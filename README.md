# Core PHP E-Commerce Website

This is my first e-commerce website built using **Core PHP**.

## Features
- Product management (CRUD)
- User-friendly interface
- Basic admin panel
- MySQL database integration

## Technologies Used
- Core PHP
- MySQL
- HTML
- CSS
- JavaScript

## Description
This project helped me understand how CRUD operations work in Core PHP using
MySQL queries. It focuses on backend logic and database handling.

## Purpose
Learning Core PHP fundamentals and building real-world logic before moving to frameworks.
